ポット計算 - セキュリティ重視版

セキュリティ設計
- 外部CDN、外部JavaScript、広告、解析タグ、外部フォントなし
- プレイヤー名・投入額をサーバーへ送信しない。ブラウザ内メモリのみで処理
- localStorage / Cookie にプレイヤー情報を保存しない
- DOM表示は textContent / createElement を使用し、入力文字列をHTMLとして解釈しない
- Content Security Policy を設定
- Service Worker は同一オリジンの静的ファイルのみキャッシュ
- 入力値は0〜1,000,000,000の整数に制限、プレイヤーは最大10人

ホーム画面への追加
PWAのインストールとService WorkerにはHTTPS配信が必要です。
1. ZIPを展開し、5ファイルを同じフォルダに置く
2. HTTPS対応の静的ホスティングへアップロード
3. Android ChromeでHTTPS URLを開き「アプリをインストール」または「ホーム画面に追加」
4. 一度起動してキャッシュを完了すると、以後オフラインで利用可能

注意
- HTTPSホスティング先のアカウント保護、公開範囲、更新管理は利用者側でも確認してください。
- HTTPSのURLを知る人はアプリ本体を閲覧できますが、入力したハンド情報は送信されません。
- これはディーラー補助ツールです。未コールベット、オールイン条件、ハウスルールを確認して最終判断してください。
- セキュリティ対策はリスク低減であり、完全な安全性を保証するものではありません。
